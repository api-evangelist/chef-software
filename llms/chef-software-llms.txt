# Chef Software

> Chef Software is the DevOps automation company behind Chef Infra, Chef InSpec, Chef Habitat, and Chef Automate (part of Progress Software). Chef pioneered infrastructure-as-code and continuous compliance. The Chef Automate API is a REST surface (generated from gRPC via grpc-gateway) for compliance, node management, configuration management, secrets, data/event feeds, and IAM. Authentication is via an API token in the `api-token` header.

## APIs

- [Chef Automate API](https://docs.chef.io/automate/api/): REST API for compliance reporting, node management, config management, secrets, data feeds, and IAM v2.
- [Chef Infra Server API](https://docs.chef.io/): Cookbook, node, role, environment and data-bag management on the Chef Infra Server.
